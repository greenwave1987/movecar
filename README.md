# 🚗 挪车通知系统（MoveCar Notify）

基于 **Cloudflare Workers + Cloudflare KV** 的轻量级网页挪车通知系统，支持上传现场照片、企业微信 / Bark 推送、车主多条记录选择回复、历史记录分页查看，以及在特定未回复条件下自动解锁拨号按钮。

## ✨ 核心功能

- **现场照片与留言通知**：提交挪车申请时必须上传现场照片（支持移动端相机拍摄或相册选择），可选填留言或快捷标签，实时写入当日 KV 记录（默认 24 小时过期）。
- **多通道推送**：支持通过 **企业微信应用消息** 与 **Bark** 推送挪车提醒，附带车主确认页链接（`/owner-confirm?id=...`）。
- **车主多记录选择与快捷回复**：车主打开确认页可查看当日申请列表（每次展开 3 条），点击切换对应申请并发送快捷回复（`马上`、`重拍`、`拒绝`）或自定义回复。
- **申请页状态轮询与操作**：
  - 发送成功后进入等待页并轮询车主回复状态。
  - 操作区包含 **再次通知**、**返回申请页**（清理轮询定时器并刷新今日记录）以及满足条件后显示的 **直接打电话** 按钮。
- **电话按钮自动解锁规则**：
  - 当日累计收到 **≥ 3 条** 未回复申请；
  - 且 **最近连续 3 条** 均未回复；
  - 且这连续 3 条中 **第 1 条（最早）与第 3 条（最新）时间间隔超过 1 分钟**（`> 60000ms`）；
  - 满足上述条件时自动显示“直接打电话”按钮（连续点击 3 次“再次通知”也可手动解锁）。

## 🚀 快速部署（Cloudflare Workers）

1. 在 Cloudflare Dashboard 创建 **KV Namespace**，并在 Worker 绑定中命名为 `MOVE_CAR_STATUS`。
2. 将 `movecar.js` 部署到 Cloudflare Worker。
3. 可选配置环境变量 / Secrets：
   - `PHONE_NUMBER`：车主联系电话（用于 `tel:` 拨号按钮）
   - `WECOM_CORPID`、`WECOM_APP_SECRET`、`WECOM_AGENTID`、`WECOM_TOUSER`（可选，默认 `@all`，多用户用 `&` 分隔）
   - `BARK_URL`（可选，Bark 推送服务地址）
